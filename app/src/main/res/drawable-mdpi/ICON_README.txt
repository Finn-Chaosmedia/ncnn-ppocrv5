OCR Scanner App Icon
====================

Dies ist ein Platzhalter-Icon. Bitte ersetzen Sie diese Datei durch ein echtes PNG-Icon.

Erforderlich:
- Dateiname: ic_launcher.png
- Größe: 48x48 Pixel
- Format: PNG mit transparentem Hintergrund
- Empfohlene Farben: Blau/Türkis für Brillanten-Design

Icon-Design-Vorschlag:
- Brillant/Diamant Symbol (Raute)
- Scanner-Strahlen (4 Linien)
- Moderne, klare Formen

Sie können das Icon mit einem Grafikprogramm erstellen oder
ein kostenloses Icon von einer Website wie:
- https://material.io/resources/icons/
- https://fonts.google.com/icons
herunterladen und anpassen.
